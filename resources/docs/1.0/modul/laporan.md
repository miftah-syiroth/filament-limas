# Laporan

Grup **Laporan** menyediakan akses ke data operasional dan historis untuk monitoring dan unduhan.

## Siapa yang Bisa Mengakses

Bergantung izin per menu. Umumnya admin dan operator dengan akses baca laporan.

## Cara Membuka

Sidebar → grup **Laporan**

## Audit Barang

Daftar seluruh inspeksi fisik yang pernah dicatat.

- Filter berdasarkan kondisi, hasil, atau tanggal
- Ekspor ke spreadsheet
- Detail lengkap: [Audit Barang](/{{route}}/{{version}}/modul/audit)

## Pemeliharaan

Daftar tiket perawatan dan perbaikan.

- Filter status dan tipe
- Ekspor data pemeliharaan
- Detail lengkap: [Pemeliharaan](/{{route}}/{{version}}/modul/maintenance)

## Barang Dipinjam

Rincian setiap item dalam transaksi peminjaman — berguna untuk melacak barang yang masih keluar.

- Filter peminjaman aktif atau terlambat
- Ekspor daftar barang dipinjam

## Riwayat Aktivitas

Log perubahan data di sistem (siapa, apa, kapan). Halaman ini **hanya baca** — tidak dapat mengubah data.

Gunakan untuk audit internal dan investigasi perubahan.

## Barang Depresiasi

Laporan nilai buku aset setelah penyusutan.

1. Buka **Barang depresiasi** di grup Laporan
2. Tinjau tabel nilai pembelian, penyusutan, dan nilai buku
3. Gunakan filter jika tersedia
4. Klik **Ekspor** untuk mengunduh laporan keuangan

## Ringkasan di Dasbor

Banyak indikator laporan juga tersedia sebagai widget di [Dasbor](/{{route}}/{{version}}/panel-admin/dashboard) — peringatan, grafik, dan tabel ringkas.
