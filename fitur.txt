================================================================================
DAFTAR FITUR SIRIS - Aplikasi Manajemen Aset/Inventori
================================================================================

## 1. ORGANISASI & LOKASI

### 1.1 Manajemen Organisasi
Status: SELESAI
Deskripsi:
  - Mengelola data perusahaan/institusi pemilik aset
  - Menyimpan informasi kontak, alamat, dan catatan organisasi
  - Mendukung soft delete untuk audit trail
  - Relasi dengan locations dan departments

### 1.2 Manajemen Lokasi/Cabang
Status: SELESAI
Deskripsi:
  - Mengelola cabang/kantor di bawah organisasi
  - Menyimpan detail alamat, kota, provinsi, negara, kode pos
  - Menghubungkan dengan departemen melalui department_locations
  - Support untuk soft delete

### 1.3 Manajemen Departemen
Status: SELESAI
Deskripsi:
  - Mengelola unit kerja/departemen dalam organisasi
  - Mendukung relasi many-to-many dengan lokasi
  - Menyimpan kontak departemen dan catatan
  - Soft delete untuk data historis

### 1.4 Manajemen Ruangan
Status: SELESAI
Deskripsi:
  - Mengelola ruangan dalam setiap lokasi
  - Menyimpan kapasitas ruangan dan catatan
  - Hubungan dengan items untuk tracking lokasi detail
  - Support soft delete


## 2. MASTER ASET

### 2.1 Manajemen Kategori Aset
Status: SELESAI
Deskripsi:
  - Klasifikasi jenis aset (asset, accessory, consumable, license)
  - Membantu kategorisasi dan pelaporan aset
  - Relasi dengan models untuk template produk
  - Support soft delete

### 2.2 Manajemen Manufaktur/Produsen
Status: SELESAI
Deskripsi:
  - Menyimpan data produsen/vendor perangkat
  - Informasi dukungan (URL, email, phone)
  - Lookup warranty dan support contact
  - Relasi dengan models

### 2.3 Manajemen Model/Spesifikasi
Status: SELESAI
Deskripsi:
  - Template/spesifikasi produk aset
  - Penyimpanan nomor model, umur pakai, interval audit
  - Alert stok minimum
  - Hubungan dengan category, manufacture, depreciation, dan unit
  - Support soft delete

### 2.4 Manajemen Penyusutan Aset
Status: SELESAI
Deskripsi:
  - Skema penyusutan aset (straight line method)
  - Konfigurasi durasi penyusutan (dalam bulan)
  - Nilai minimum penyusutan
  - Relasi dengan models untuk perhitungan nilai aset

### 2.5 Manajemen Unit Pengukuran
Status: SELESAI
Deskripsi:
  - Satuan pengukuran (pcs, box, kg, dll)
  - Referensi untuk models dan items
  - Support berbagai jenis unit

### 2.6 Manajemen Supplier/Pemasok
Status: SELESAI
Deskripsi:
  - Menyimpan data pemasok/vendor pengadaan
  - Informasi kontak dan alamat lengkap
  - Detail website dan informasi bisnis
  - Hubungan dengan items untuk tracking supplier


## 3. REFERENSI GEOGRAFIS

### 3.1 Master Data Negara
Status: SELESAI
Deskripsi:
  - Daftar negara dengan kode unik
  - Digunakan sebagai referensi untuk lokasi dan supplier
  - Tanpa foreign key database - relasi via kode

### 3.2 Master Data Provinsi
Status: SELESAI
Deskripsi:
  - Daftar provinsi per negara
  - Relasi logis ke negara via country_code
  - Digunakan untuk lokasi dan supplier

### 3.3 Master Data Kota
Status: SELESAI
Deskripsi:
  - Daftar kota per provinsi
  - Relasi logis ke provinsi via province_code
  - Support untuk geographic filtering


## 4. INVENTORI

### 4.1 Manajemen Item/Aset Individual
Status: SELESAI
Deskripsi:
  - Mengelola unit aset individual - pusat inventori
  - Tracking nomor seri (unique), kuantitas, tanggal pembelian
  - Status aset (active, under_diagnosis, under_repair, damaged, irreparable, lost, stolen, archived, disposed)
  - Informasi end-of-life, warranty, dan tracking terpisah
  - Audit trail dengan last_audit_date dan next_audit_date
  - Hubungan dengan users (penanggung jawab), models, locations, departments, suppliers, rooms
  - Support soft delete

### 4.2 Pergerakan Stok
Status: SELESAI
Deskripsi:
  - Tracking pergerakan stok untuk item consumable
  - Tipe pergerakan: in, out, adjustment
  - Quantity positif/negatif sesuai tipe
  - Catatan transaksi untuk audit
  - Relasi dengan items dan support soft delete


## 5. OPERASIONAL

### 5.1 Item Audit/Inspeksi
Status: SELESAI
Deskripsi:
  - Catatan audit/inspeksi aset berkala
  - Status hasil (passed, failed)
  - Kondisi aset (excellent, good, fair, poor, unusable)
  - Rekomendasi hasil (ok, needs_maintenance, needs_replacement, dispose)
  - Verifikasi lokasi aset saat audit
  - Scheduling audit berikutnya
  - Relasi dengan items, maintenances, dan item_state_logs

### 5.2 Manajemen Perawatan/Perbaikan
Status: SELESAI
Deskripsi:
  - Tracking perawatan dan perbaikan aset
  - Tipe maintenance: preventive, repair, upgrade, inspection
  - Status progress: reported, in_progress, completed, cancelled
  - Tracking waktu (reported, started, completed)
  - Pencatatan biaya perawatan
  - Hubungan dengan items dan item_audits

### 5.3 Item State Logs
Status: SELESAI
Deskripsi:
  - Jejak perubahan lokasi, penugasan, dan status aset
  - Event types: transfer, assignment, status_change
  - Snapshot posisi dari/ke (location, department, room, user, status)
  - Audit trail lengkap untuk setiap perubahan
  - Relasi dengan items, item_audits, maintenances, locations, departments, rooms, users

### 5.4 Manajemen Peminjaman/Pemindahan Sementara
Status: SELESAI
Deskripsi:
  - Fitur untuk memindahkan aset sementara ke lokasi lain
  - Konsep: peminjaman = pemindahan posisi sementara
  - Tracking peminjam (user), tanggal keluar, tanggal kembali
  - Support multiple items per transaksi peminjaman
  - Status: active, returned
  - Catatan bebas untuk keterangan transaksi (alasan, event, PIC, dll)
  
  Fitur rencana refactor:
  - Tujuan sementara per transaksi (location, department, room)
  - Snapshot posisi asal dan tujuan per item
  - Update otomatis positions saat keluar/kembali
  - Per-item override tujuan dari default header
  - Kondisi aset saat keluar dan kembali
  - Validasi: minimal satu tujuan wajib diisi
